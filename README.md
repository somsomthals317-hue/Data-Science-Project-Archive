### 01. 특허 데이터를 활용한 녹색/기후 기술과 ICT 기술 간의 기술 융합 분석

- **발표자료:** [Term Project PDF](%23%202-2%20소네과%205조%20Term%20Project%20발표%20자료.pdf)

### 02. 보험사의 지급여력비율 예측
- **목적:** 재무비율 및 외부 경제지표를 활용해 보험사의 지급여력비율을 예측하고, 재무 건전성 판단에 영향을 미치는 주요 변수 분석
- **주제:** 재무비율과 외부 경제지표를 활용한 보험사 지급여력비율(RBC) 예측
- **분석:** Feature Selection(RFECV), 회귀·분류 모델링, 시계열 교차검증
- **발표자료:** [Term Project PDF](%23%203-1%205대%20재무비율을%20활용한%20머신러닝%20Term%20Project%20발표자료.pdf)

### 03. 협찬 로그 기반 관계 패턴 학습을 통한 인플루언서 추천 시스템 연구
- **목적:** 과거 협찬 이력을 기반으로 브랜드와 인플루언서 간 관계 패턴을 학습하여, 브랜드의 협찬 파트너 선정 및 검증 의사결정 지원
- **주제:** 브랜드·인플루언서 협찬 이력을 활용한 Implicit Feedback 기반 추천
- **분석:** Matrix Factorization(ALS), NeuMF, Hybrid NeuMF, HR@K, NDCG@K
- **발표자료:** [Term Project PDF](%23%203-2%20브랜드%20X%20인플루언서%20추천시스템%20Term%20Project%20발표자료.pdf)
